## 3. Method and evidence

- **Dedupe** (`tmp/imagery/group.mjs`): master key = CDN URL before "@w_"; the storage.googleapis.com families (`___responsive_W_H`, `conversions/<uuid>-responsive`, `external/<uuid>.<ext>`) key on folder + uuid; then any two masters sharing a sha256 are merged (3 stock photos uploaded twice, 10 byte-identical width variants each). Self-checks: all 1131 sources covered once, no sha256 split across masters.
- **Context** (`tmp/imagery/contexts.mjs`, one headless Chrome via `tools/cdp.mjs`, saved pages served from an in-process server, academyvisionnj.com and trackers blocked): every CSS rule with a `url()` (including those inside media queries), every `img`/`srcset`/`source`, head links and JSON-LD mapped to its component chain and rendered width at 1440 px. All 139 masters have at least one reference and no page image is missing from the inventory; both checks fired on planted positive controls.
- **Fingerprints**: dHash/aHash per master to find visual duplicates the sha256 rule cannot see (one confirmed photo pair). The verifier's own re-hash also pairs the two current-logo files, `logo-academy-vision-1200` and `logo-academy-vision-400` (the same mark at two sizes, now flagged too).
- **Viewing**: 10 photos as individual files, 74 on 2x2 contact sheets (`tmp/imagery/sheets/s01-s19.png`, full frame on grey with rule-of-thirds guides), notes written per sheet to `tmp/imagery/notes.jsonl`. The task's cap ("view the 60 largest if more than 60") would have skipped the smallest files, which are exactly the real people and the real building, so all 84 were viewed instead.
- **Logo backgrounds** (`tmp/imagery/alpha.mjs`): alpha share, corner alpha and non-white ink box measured on every logo-type file; 12 rendered on #ffffff and #0f2a4a. The thresholds: transparent means alpha below 8, semi-transparent means alpha 8-247, and the ink box covers pixels with alpha 8 or more that are not near-white (near-white = all three RGB channels above 245).
- **CDN originals** (`tmp/imagery/cdn-probe.mjs`): 64 HTTP Range probes to cdn.patientengage.cloud, one per file, all answered 206. Each probe requests bytes 0-131071, the first 128 KB of the file, which holds the header. For the 3 files under 128 KB that window is the whole file. About 7.9 MiB was read in all, held in memory and discarded; nothing was saved to disk and academyvisionnj.com was never contacted.
- **Brand palette** confirmed in the saved CSS: on the home page #0f2a4a appears 93 times, #3974a0 51, #f9f4f0 26, #4489bc 19.

## 4. Quality rules

- **hero/background**: full-bleed up to 1440 css px at DPR 2: OK >= 2400 px wide (task rule); TINY < 1200 = under half the OK width (lane rule); else LOW-RES-FOR-ROLE
- **section photo**: half width: OK >= 1200 px wide; TINY < 600; else LOW-RES-FOR-ROLE (task rule)
- **team portrait**: bio portrait at half width: OK >= 1200; TINY < 600 (lane rule, same thresholds as section photo)
- **logo**: header logo up to 280 css px at DPR 2: OK >= 560; TINY < 280 (lane rule)
- **brand logo**: logo tile up to 200 css px at DPR 2: OK >= 400; TINY < 200 (lane rule)
- **badge/award**: badge up to 150 css px at DPR 2: OK >= 300; TINY < 150 (lane rule)
- **icon/ui and other (6 files)**: no width threshold; each call rests on its own `qualityBasis` in the masters JSON. The 4 SVGs are OK as vectors. `icon-favicon` is OK because favicon and apple-touch-icon need 180 px or more and the file is 200 px. `ui-divider-stripe` is LOW-RES-FOR-ROLE because a 1600x18 raster is stretched full-bleed (a `background-size: cover` layer). (Added by the verifier from the JSON.)
- **note**: quality is called on the best LOCAL file (largest intrinsic width). qualityIfOriginalFetched is the call on the CDN master original measured by tmp/imagery/cdn-probe.mjs.
